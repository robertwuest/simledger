# SimLedger

Graph Visualization adapted from http://raphaeljs.com/ and https://www.graphdracula.net/

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
